Try for Tomorrow — Working Demo

An interactive walkthrough of the Try for Tomorrow pledge tool.

What you're looking at. Try for Tomorrow runs a 6-session programme with young people. After each session's video, every student takes a turn on a shared device, picks a pledge and kicks it over the posts. This demo lets you play all three roles: the facilitator running a session, the pledge widget students use, and the admin console that sees every provider's results. It comes pre-filled with a fictional programme — six schools and clubs, ~600 pledges — so there's history to explore.
1 · Facilitator pathway → tap Alex → the Dashboard 2 · Year 9 Rugby → Session 5 → Girls → pledge time 3 · Admin console — watch it arrive, moderate own ideas
Sandbox mode — your own private copy. Everything runs inside your browser: nothing you type is sent anywhere, and no one else can see it. The website and database are simulated so the whole flow works without accounts. It's safe to experiment, and Reset all demo data at the bottom starts you fresh.
Mode: Live mode isn't configured yet.
Live mode — a shared demo database. Pledges and totals are saved to a real Firebase database and appear on every device in Live mode, so a pledge made on a phone shows up on the admin console on a laptop. Student names still never leave this browser: the roster stays here, and only a pseudonymous ID is shared. Everything in Live mode is visible to anyone else using the demo, so please don't type real names into pledges.
