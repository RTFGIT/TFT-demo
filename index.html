Try for Tomorrow — Working Demo

An interactive walkthrough of the Try for Tomorrow pledge tool.

What you're looking at. Try for Tomorrow runs a 6-session programme with young people. After each session's video, every student makes a pledge on a shared device, and a rugby ball is kicked over the posts as each one lands. This demo lets you play all three roles: the facilitator running a session, the pledge widget students use, and the admin console that sees every provider's results.
1 · Open the Facilitator pathway and sign in 2 · Create a cohort, add a few students, run a session 3 · Open the Admin console to see the pledges arrive
Sandbox mode — your own private copy. Everything runs inside your browser: nothing you type is sent anywhere, and no one else can see it. The website and database are simulated so the whole flow works without accounts. It's safe to experiment, and Reset all demo data at the bottom starts you fresh.
