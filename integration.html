How the widget embeds on WordPress

The facilitator portal you tested is a stand-in for WordPress. Only one small piece is the actually-embeddable widget. This page shows exactly where that seam is.

The three layers

🔒 1 · WordPress
tryfortomorrow.org
  • Facilitator login
  • Real student names
  • Cohort / group / session pages
  • Embeds the widget + hands it a student
▶
◈ 2 · The widget
GitHub Pages · public_widget/
  • The question, options & counter
  • Captures the pledge
  • Name-blind — only a p_… ref
  • Writes straight to Firebase
▶
☁ 3 · Firebase
Firestore
  • Runs & pledges
  • Session content
  • Counters
  • Never a name

Only layer 2 is uploaded as static files and embedded. The whole facilitator/ folder in this demo is a local stand-in for layer 1 — in production those are WordPress pages and a plugin, not HTML you upload.

The embed code

1 — drop the iframe onto the WordPress page (URL carries only non-identifying routing):

<iframe id="tft-pledge"
  src="https://rtfgit.github.io/TFT/pledge-widget.html?provider=demo-college&session=3&run=abc123&cohort=year-9-rugby"
  title="Try for Tomorrow pledge" style="width:100%;border:0"></iframe>

2 — hand the widget each student. The name is shown on screen but never travels to Firebase:

// WordPress knows the names; the widget only ever gets the pseudonymous ref.
frame.contentWindow.postMessage({
  type: 'TFT_SET_STUDENT',
  student_ref: 'p_a7f3c21b',   // stored
  display_name: 'Jack S.'       // shown only, never persisted
}, 'https://rtfgit.github.io');

// messages the widget posts back:
//   TFT_WIDGET_READY · TFT_PLEDGE_SAVED · TFT_STUDENT_SKIPPED · TFT_READY_FOR_NEXT · TFT_HEIGHT
// and one more the page may send:  TFT_ALL_DONE  (everyone has had a turn)

What deploys where

GitHub Pages (the widget)WordPressFirebase
public_widget/ — pledge-widget.html, pledge-widget-app.js, session-config.js, assets/ facilitator login & portal pages · the roster (names) · a plugin for roster REST + run orchestration · the iframe embed runs · pledges (by student_ref) · session content · counters

facilitator/ and wp-emulator.js deploy nowhere — they only stand in for WordPress locally. Full contract: public_widget/IFRAME_INTEGRATION.md.
